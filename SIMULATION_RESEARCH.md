## 2. Key Patterns & Design Mechanisms

### Core Design Patterns from External Simulations

#### A. Multi-Round Decision Cycles
- **Pattern**: Quarterly/periodic decision rounds with feedback
- **Why It Works**: Creates realistic business rhythm, allows strategy adjustment
- **Implementation**: Fixed decision windows, cumulative effects, historical tracking
- **Found in**: Markstrat, Capsim, Cesim, Hubro, SimVenture

#### B. Competitive Dynamics
- **Pattern**: Real-time or turn-based competition against peers/AI
- **Why It Works**: Increases engagement, simulates market pressure
- **Implementation**: Share of voice models, market share calculations, competitor AI
- **Found in**: All surveyed simulations

#### C. Feedback Loops
- **Pattern**: Immediate performance reports after decisions
- **Why It Works**: Reinforces learning, enables strategy adjustment
- **Implementation**: Dashboards, KPI tracking, trend visualization
- **Found in**: Simbound, Capsim, Hubro, Marketplace

#### D. Progressive Complexity
- **Pattern**: Increasing difficulty/features over time
- **Why It Works**: Prevents overwhelm, builds competence gradually
- **Implementation**: Phased feature unlocks, difficulty levels, tutorial systems
- **Found in**: Marketplace, GoVenture, SimVenture

#### E. Achievement & Badge Systems
- **Pattern**: Milestone recognition with visible rewards
- **Why It Works**: Creates intrinsic motivation, progress visibility
- **Implementation**: Achievement trees, rarity tiers, point systems
- **Found in**: Most modern simulations

#### F. Leaderboards & Rankings
- **Pattern**: Competitive rankings with filters and categories
- **Why It Works**: Social proof, healthy competition, goal-setting
- **Implementation**: Global/industry/time-based boards, percentile rankings
- **Found in**: Simbound, Stukent, GoVenture

#### G. Team/Multiplayer Mode
- **Pattern**: Collaborative or competitive group play
- **Why It Works**: Mirrors real business environments, builds soft skills
- **Implementation**: Team roles, shared decisions, communication features
- **Found in**: Markstrat, Capsim, Hubro, most enterprise sims

#### H. Adaptive Difficulty
- **Pattern**: Dynamic challenge adjustment based on performance
- **Why It Works**: Maintains engagement for all skill levels
- **Implementation**: AI difficulty scaling, personalized scenarios
- **Found in**: Stukent Mimic, GoVenture

#### I. Comprehensive Analytics/Reports
- **Pattern**: Detailed post-decision and post-simulation analysis
- **Why It Works**: Deep learning, actionable insights
- **Implementation**: Financial statements, market reports, comparative analysis
- **Found in**: Capsim, Hubro, Markstrat

#### J. Risk-Free Experimentation
- **Pattern**: Safe environment to try strategies without real consequences
- **Why It Works**: Encourages exploration, reduces fear of failure
- **Implementation**: Reset options, scenario branching, "what-if" analysis
- **Found in**: All educational simulations

## 4. Proposed Feature Improvements

### Quick Wins (Low Effort + High Value) 🚀

#### QW-1: Enhanced Leaderboard with Time Periods
- **Description**: Add daily/weekly/monthly/all-time tabs to leaderboard
- **Why It Helps**: Creates ongoing engagement, fresh competition cycles (Simbound, GoVenture pattern)
- **Integration**: Extend existing leaderboard component, add filter state
- **Files**: `src/app/leaderboard/`, new `LeaderboardFilters.tsx`
- **Effort**: 2-4 hours

#### QW-2: Daily Challenges System
- **Description**: Daily rotating marketing challenges with bonus rewards
- **Why It Helps**: Drives daily engagement, skill-building in specific areas (Duolingo/Simbound pattern)
- **Integration**: New component, store in Supabase, gamification hook
- **Files**: New `src/components/gamification/DailyChallenges.tsx`, new API route
- **Effort**: 4-6 hours

#### QW-3: User Level & Progress System
- **Description**: XP-based levels with progress bars, unlock cosmetics/features
- **Why It Helps**: Creates long-term progression, visible growth (GoVenture, all modern games)
- **Integration**: Extend user profile, add XP tracking, level thresholds
- **Files**: Extend `types/index.ts`, new `LevelProgress.tsx` component
- **Effort**: 3-5 hours

#### QW-4: Streak Counter & Rewards
- **Description**: Track consecutive day engagement, bonus multipliers
- **Why It Helps**: Builds habit, increases retention (Duolingo pattern, proven effective)
- **Integration**: Add streak field to user profile, daily check-in logic
- **Files**: Extend profile schema, new `StreakBadge.tsx`
- **Effort**: 2-3 hours

#### QW-5: Achievement Progress Tracking
- **Description**: Show progress toward each achievement (40% complete, etc.)
- **Why It Helps**: Creates near-miss motivation, clear goals (all gamified platforms)
- **Integration**: Extend existing achievement system, add progress calculation
- **Files**: Extend `AchievementBadge.tsx`, add progress props
- **Effort**: 2-4 hours

## 6. Technical Integration Notes

### Database Schema Extensions

```sql
-- Daily Challenges Table
CREATE TABLE daily_challenges (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES auth.users(id),
  challenge_type VARCHAR(50) NOT NULL,
  challenge_data JSONB NOT NULL,
  completed BOOLEAN DEFAULT false,
  completed_at TIMESTAMP WITH TIME ZONE,
  reward_points INTEGER DEFAULT 0,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- User Streaks Table
CREATE TABLE user_streaks (
  user_id UUID PRIMARY KEY REFERENCES auth.users(id),
  current_streak INTEGER DEFAULT 0,
  longest_streak INTEGER DEFAULT 0,
  last_activity_date DATE,
  streak_multiplier DECIMAL(3,2) DEFAULT 1.0
);

-- User Levels Table
CREATE TABLE user_levels (
  user_id UUID PRIMARY KEY REFERENCES auth.users(id),
  current_xp INTEGER DEFAULT 0,
  current_level INTEGER DEFAULT 1,
  total_xp_earned INTEGER DEFAULT 0,
  level_up_history JSONB DEFAULT '[]'
);
```

### Component Architecture

```
src/components/gamification/
├── DailyChallenges.tsx       # Daily challenge cards
├── StreakBadge.tsx           # Streak display & animation
├── LevelProgress.tsx         # XP bar & level display
├── AchievementProgress.tsx   # Progress toward achievements
├── LeaderboardFilters.tsx    # Time period & category filters
└── index.ts                  # Barrel export
```

### State Management

```typescript
// Gamification Store Extension
```
